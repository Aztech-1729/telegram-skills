# Primary sources

Reviewed **2026-10-04**. Original component/layout recommendations complement
these platform and accessibility references.

- [Telegram Mini Apps](https://core.telegram.org/bots/webapps): theme parameters, CSS variables, native controls and API-version gates.
- [BottomButton](https://core.telegram.org/bots/webapps#bottombutton), [BackButton](https://core.telegram.org/bots/webapps#backbutton) and [events](https://core.telegram.org/bots/webapps#events-available-for-mini-apps): handler lifecycle and responsive behavior.
- [W3C contrast minimum](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) and [non-text contrast](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html): text/control contrast checks.
- [W3C reflow](https://www.w3.org/WAI/WCAG22/Understanding/reflow.html) and [focus not obscured](https://www.w3.org/WAI/WCAG22/Understanding/focus-not-obscured-minimum.html): narrow layout and focused-control visibility.

Native button RGB customization applies to Mini App controls, not ordinary bot
keyboards. This ledger records documentation review, not a live-client certificate.
